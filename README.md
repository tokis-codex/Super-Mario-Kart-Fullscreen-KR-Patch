Psicopompo님의 전체화면 패치에 대응하는 한글패치입니다.<br>
https://www.romhacking.net/hacks/10083/<br><br>

원본 풀스크린 패치의 업데이트가 멈추지 않은 관계로 한글패치 버전별로 패치를 해야 할 원본 롬의 해시(Hash) 값이 다를 수 있습니다.<br>

아무런 패치도 적용되지 않은 원본 롬의 해시(Hash) 값은 아래와 같습니다.<br><br>

Database match: Super Mario Kart (USA)<br>
Database: No-Intro: Super Nintendo Entertainment System (v. 20210222-050638)<br>
File/ROM SHA-1: 47E103D8398CF5B7CBB42B95DF3A3C270691163B<br>
File/ROM CRC32: CD80DB86<br>

기본적으로 위의 순정롬파일에 Psicopompo님의 전체화면 패치를 적용한 후, 추가로 이 곳에서 배포되는 한글패치를 적용하는 방식입니다.<br><br>
